# Cluster-IDE: Cross-Device Deployment Strategy
**Document ID:** `IDE-PLN-004`  
**Target Matrix:** Android, Apple (iOS/macOS), Windows, Linux, and Modern Web  

---

## 1. Unified Cross-Device Deployment Philosophy

Most cross-platform tools force developers to rewrite their application or use heavy runtimes:
* Electron adds 150 MB and 800 MB RAM on desktop.
* Flutter adds a 15 MB canvas engine on web.
* React Native requires JavaScript bridges.

**Cluster-IDE uses Direct Host Lowering:**  
A single Cluster UI codebase compiles to the natural native format of each target operating system:

```
                          Cluster-IDE Core Codebase
                                      │
        ┌─────────────┬───────────────┼───────────────┬─────────────┐
        ▼             ▼               ▼               ▼             ▼
    [ Web PWA ]    [ Linux ]      [ Windows ]     [ Android ]    [ Apple ]
    Zero-Install   Native ELF     Native .exe     Native APK     macOS / iOS
    Browser IDE    + WebKitGTK    + WebView2      + Jetpack UI   + SwiftUI
```

---

## 2. Platform-Specific Target Specifications

### Target A: Modern Web (Zero-Install Cloud & PWA)
* **Output:** Semantic HTML5, CSS3 GPU compositor, and Cluster Reactive Micro-Runtime (< 0.4 KB).
* **Compiler Backend:**
  * Cloud mode: Connects to `server.cl` over WebSocket / HTTP.
  * Local WebAssembly mode: Uses `cl --target wasm32-wasi` to compile and run code entirely inside client browser threads with Web Workers!
* **Installation:** PWA (Progressive Web App) — can be installed to desktop or mobile home screen with 1 click.

### Target B: Linux (Workstation & Cloud Server)
* **Output:** Native 64-bit ELF executable (`cluster-ide-linux-x86_64` / `aarch64`).
* **Packaging:** Single self-contained binary + AppImage / Flatpak / `.deb`.
* **Window Host:** Lightweight WebKitGTK or Chrome App shell (< 15 MB memory footprint).
* **Compiler:** Direct invocation of `/usr/local/bin/cl` at bare-metal speed.

### Target C: Windows (10 & 11)
* **Output:** Native Win32 PE executable (`cluster-ide-win64.exe`).
* **Window Host:** Microsoft Edge WebView2 control (built into all Windows 10/11 machines, zero extra download).
* **Compiler:** Embedded `cl.exe` targeting LLVM/MSVC.

### Target D: Android (Tablets & Phones)
* **Output:** Native Android `.apk` package.
* **Architecture:**
  * Main Shell: Android Activity hosting Android Jetpack layouts generated by Cluster UI.
  * Local Engine: ARM64 Cluster compiler binary (`cl`) bundled inside the app's native library path (`/data/data/com.cluster.ide/bin/cl`).
  * Features: Full file system access via Android Storage Access Framework (SAF), external keyboard shortcuts (`Ctrl+R` to run).

### Target E: Apple (macOS & iOS/iPadOS)
* **Output:** Native Universal Apple `.app` bundle.
* **Architecture:**
  * Shell: Native SwiftUI `WindowGroup` with macOS menus (`MenuBarExtra`, NavigationSplitView).
  * iOS/iPadOS: iPad Multitasking & Stage Manager support.
  * Compiler: Clang/LLVM toolchain targeting macOS Universal Binary (Apple Silicon M1/M2/M3/M4 + Intel x86_64).
